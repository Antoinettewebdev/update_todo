# Update To-Do

A minimalist Flutter to-do app backed by Firebase. Users sign in with Google, then create, update, and delete personal to-do items stored in Cloud Firestore.

## Stack

- **Frontend:** Flutter (Dart)
- **Backend:** Firebase Auth + Cloud Firestore
- **Auth:** Google Sign-In (primary login method)
- **IDE / testing:** Android Studio with emulator or physical device

## Features

- Google Sign-In via Firebase Authentication
- Sign out from the main list screen
- CRUD to-dos per user (`users/{uid}/todos/{id}`)
- Swipe-to-delete on the list; full edit screen for create/update

## Screens

1. **Login** — Continue with Google
2. **To-Do list** — Streamed items, checkbox toggle, FAB to add, sign-out
3. **Detail / create** — Title, description, save, delete (edit only)

## Firebase setup

1. Create a project in the [Firebase Console](https://console.firebase.google.com/).
2. Enable **Authentication → Google** sign-in provider.
3. Create a **Firestore** database (production or test mode; deploy rules below for production).
4. Install FlutterFire CLI and configure the app:

   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```

   This generates `lib/firebase_options.dart` and downloads `android/app/google-services.json` (and iOS config).

5. Deploy Firestore security rules from this repo:

   ```bash
   firebase deploy --only firestore:rules
   ```

   Or paste `firestore.rules` into the Firebase Console → Firestore → Rules.

6. **Android — Google Sign-In SHA-1**  
   Add your debug/release SHA-1 in Firebase → Project settings → Your apps → Android app.  
   Get debug SHA-1:

   ```bash
   cd android
   ./gradlew signingReport
   ```

7. **iOS (optional)**  
   Add `GoogleService-Info.plist`, enable Google provider, and set the reversed client ID in `ios/Runner/Info.plist` under `CFBundleURLTypes`.

## Run

```bash
flutter pub get
flutter run
```

Use an Android emulator from Android Studio or a connected device.

## Firestore data model

users/{userId}/todos/{todoId}

  description: string
  completed: bool
  createdAt: timestamp
  updatedAt: timestamp
